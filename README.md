# VELIXEO Releases

Official public Android release channel for **VELIXEO**.

This repository intentionally contains **release artifacts only**:
- Signed Android APK files
- `SHA256SUMS.txt` integrity manifests

The VELIXEO application source code and backend remain private.

## Security

VELIXEO verifies the published SHA-256 checksum before allowing a downloaded APK to be installed. Android also requires every upgrade to be signed with the permanent VELIXEO release key.
